% The self-driven load↔charge loop (§5.7–§5.8) on a barbell: two cliques joined by ONE bridge edge, so
% all cross-cluster current funnels through the bridge hub, which self-measures that load and glides its
% screening charge µ toward Crowd·load (no injected stress, the loop is internal). Measured from the
% async reference implementation. TWO panels:
%   TOP — the hub's charge trajectory at the three named couplings, normalised to each curve's own
%     equilibrium µ∞ so they overlay; every curve climbs monotonically to 1 with no overshoot — the
%     damped settle the non-overshoot integrator guarantees (Lemma 5.8).
%   BOTTOM — the realized loop gain Γ(c)=c·s'(µ*) at the operating point µ*=c·s(µ*), swept over coupling.
%     The up-gradient load SATURATES (s'→0 as µ grows), so the realized gain (solid) stays far below the
%     Γ=1 instability threshold at EVERY coupling and FALLS as c rises — there is no instability boundary.
%     The naive gain a fixed light-load slope would predict (dashed) shoots past 1; saturation defeats it.
% Data: congestion_ts.dat, congestion_gain.dat. Needs \usepgfplotslibrary{fillbetween} (loaded globally).
